# Mündlich

Kleine Web-App zum Erfassen mündlicher Mitarbeit im Unterricht (iPad/Tablet), Teil eines
privaten Bewertungstools.

- Enthält nur Programmcode, keine Daten.
- Klassenlisten und Einträge bleiben ausschließlich im lokalen Speicher des Geräts;
  es wird nichts an einen Server übertragen.
- Austausch mit dem Bewertungstool am PC über Dateien (Export/Import).
